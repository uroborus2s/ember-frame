# 《断航故土》项目总文档

managed_by: project-office
last_updated: 2026-06-20
status: draft_needs_user_confirmation

本文件只记录项目稳定规格和最终成果要求，不记录过程讨论。目录、交接和返工规则见 `project-management.md`；长期复用经验见 `project-memory.md`。

## 1. 项目定位

- project_id: severed-homeland
- 项目类型：AI 剧 / 系列化影像项目
- 当前阶段：故事原著 locked，编剧 in_progress，导演分镜 not_started
- 当前正式角色入口：`director-room/characters/`

## 2. 画面规格

当前默认：

- 画幅比例：16:9，若后续平台要求竖屏或方屏，必须在本文件更新。
- 分镜最终图片：以 4K UHD 画面为当前交付目标，即 3840 x 2160 或同等清晰度。
- 重要母资产 / 角色主图 / 场景母版：优先保留可上采样到 4K 的版本；是否需要 8K 母版待用户确认。
- 预览图：允许低于 4K，但必须清楚标记为 preview，不得冒充最终图。

未确认：

- 是否全项目强制 8K 母资产。
- 是否需要竖屏平台版本。
- 是否需要 HDR、宽色域或特定色彩管理。

## 3. 视频规格

当前默认：

- 最终成片目标：4K UHD，3840 x 2160。
- 工作预览：允许 1920 x 1080，但必须标记 preview。
- 帧率：待导演和交付部确认；未确认前不得把工具默认帧率写成最终规格。
- 编码、码率、封装格式：待成片交付部确认。
- 单分镜最终视频：进入对应 `director-room/{season-id}/{episode-id}/{shot-group-id}/{shot-id}/{shot-id}.mp4`。

硬规则：

- 视频生成部不得用低清、糊脸、身份漂移或空间漂移素材冒充通过版。
- 如果工具只能生成低于项目目标的素材，必须在 `.project/blockers.md` 或交接风险中说明。

## 4. 音频规格

当前默认：

- 交付音频采样率：48 kHz 为目标。
- 角色配音、音乐和剪辑音频最终规格由配音部、音乐部、剪辑部和成片交付部在启动阶段确认。
- 工作试听版可以低于最终规格，但必须标记 preview。

未确认：

- 声道：stereo / 5.1 / 其他。
- loudness 标准。
- 最终音频格式与码率。

## 5. 字幕与文字

- 字幕是否作为最终交付必需项：待确认。
- 视频画面内不允许由生成模型自由生成重要文字、旗帜文字、印章文字或 UI 字样。
- 需要精确文字时，优先后期合成或剪辑阶段处理。

## 6. 交付与验收

- 预览版必须明确标记 preview。
- 最终版必须通过导演终审和成片交付 QC。
- 最终文件命名、目录和版本归口按 `project-management.md` 执行。
- 本文件未确认项不能由单个生产部门擅自默认；需要项目办公室协调用户、导演或成片交付部确认。
