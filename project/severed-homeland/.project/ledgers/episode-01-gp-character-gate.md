## 1. 导演更正裁决

G-P/P-01 至 P-05 不允许跳过角色卡进入正式参考帧、动作、运镜或视频生成。声音、三视图 / 五视角、身高比例、角色身份和可见道具均以 `director-room/characters/` 中的角色卡为第一依据；角色卡缺项时，先补角色卡，再构建视觉场景、动作和运镜。

已生成的 G-P 画面没有把角色卡图片作为硬参考输入，因此全部降级为构图 / 气氛候选。正式 `P-01.png` 至 `P-05.png` 已撤回；候选图仅保留在美术隐藏版本库，不得交给视频部作为 first_frame / identity / style。

## 4. 对各部门命令

- 美术部：保留候选图为构图参考，不得把候选图晋升正式；下一轮必须把 `director-room/characters/*.png` 作为硬身份参考，重新生成 / 合成每镜正式 `P-XX.png`。
- 配音部：C001、C002、C007、C016、C017、C024、C025、NAR001 的声音 preview 均需人工听审、切分分镜台词，并把最终音频按项目规格确认或重采样。C021 preview 已补成 48 kHz stereo 声效方向小样，但仍需人工听审、分层 stem / 终混判断，不能直接进成片。
- 提示词部：下一轮提示词必须显式引用角色卡硬锁、身高比例链和声音闸门；不得以当前候选图替代角色卡。
- 视频生成部：当前不得使用 `P-XX.png` 作为 first_frame，因为正式文件已撤回；只能在角色卡闸门通过并重新生成正式帧后 preflight。
- 剪辑 / 交付：继续等待通过角色卡闸门、参考帧 QC、音频 QC 和视频 QC 的素材。

## 5. 导演当前不满足清单

视觉角色卡层面：G-P 直接相关 C001、C002、C007、C016、C017、C021、C024、C025 的透明 V2 角色母图和身高 / 比例锁已满足导演开画要求；美术部可以用它们作为硬身份参考重做正式帧。

声音角色卡层面仍不满足最终开拍要求：

- C001、C002、C007、C016、C017、C024、C025、NAR001：均只有 preview 或试声状态，缺人工听审、分镜台词切分和最终 48 kHz 成片音频确认。
- C021：已有 `c021-creature-sfx-v001-preview.wav`，但仍缺人工听审、可拆分层声效 stem、与骨钟 / 床弩 / 军户喊声的避让测试和终混。
- C025：P-03 儿童旧歌 / 晒药名文本已由总导演锁定为 `白芷晒，薄荷晾，陈皮翻一翻。`；仍缺儿童试唱、人工听审、口型时间和最终 48 kHz 音频，未完成前不得进视频正式生成。

导演命令：配音部和音乐 / 声效部继续处理上述声音卡缺口；美术部可以并行准备角色卡硬参考重制正式帧，但视频生成部不得把任何 preview 音频或候选图当成正式开拍素材。
