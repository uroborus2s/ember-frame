# 《断航故土》项目长期记忆

managed_by: project-office / project-memory-curator
last_updated: 2026-06-20

本文件只保存会反复指导后续生产的项目级经验。它不是过程日志，也不记录每轮尝试。

## 原著与剧本表达

适用范围：原著返修、编剧改编、导演拆解、配音台词、剪辑判断。

结论：

- 世界名著级目标不能靠堆设定、喊主题或写碑文式句子完成，必须补生活肌理、人性暧昧、私人欲望和行动代价。
- 宏大主题要通过物件、选择和后果显影，不要频繁用台词替观众总结。
- 低魔史诗要把压迫落到白册、粮牌、腕骨、木牌、红线、血盐、残页、门闩、押车、账本等可见物件。
- 旧文明、法术和战争规则必须写成代价、工程、身体反应和路线感，不写成无约束奇观。

以后怎么做：

- 编剧改编时，不能把小说里的抽象主题句直接搬成口播台词，必须转成可听、可演、可剪的行动台词。
- 导演拆分镜时，优先寻找“物件承载主题”的镜头，不用旁白解释主题。
- 美术和视频制作应优先抓具体物件、制度痕迹、身体代价和空间压迫，不用空泛史诗感替代叙事。

## 台词与旁白

适用范围：编剧、导演、配音、剪辑。

结论：

- 台词先说眼前事，再说意义；先说欲望、恐惧、要求，再说隐喻。
- 每段对白原则上只承载一个世界观专名。
- 官府台词短、硬、带后果；民间台词讲吃亏、活命、亲人、价钱、路和账。
- 格言化对白、反题句、暗语、半句和诗性意象只能少量使用，过量会让人物说话像碑文。
- 旁白只补压迫感和可拍动作，不替角色解释世界观。

以后怎么做：

- 配音部发现台词读起来像碑文或判词，但角色身份不是官府、仪式、宣誓场景时，应标记返修。
- 剪辑部发现观众必须读设定集才能理解一句关键台词时，应退回台词精修，不用补旁白硬解释。
- 台词精修不得改变主线事件、角色归属、道具规则、路线、季终钩子或下游交接。

## 项目管理与读取边界

适用范围：所有部门。

结论：

- 各部门不直接翻历史文件夹找经验；项目办公室负责把长期经验压缩进本文件，再在交接或部门启动包里摘出相关部分。
- 普通过程状态、旧生产结论、临时复盘和被正式 Bible 吸收的材料，不进入本文件。
- 若某条经验只影响一个临时文件或一次失败尝试，留在 `.work/`、`.history/` 或 `.project/revision-log.jsonl`，不进入长期记忆。

以后怎么做：

- 每次部门交接、每集完成、重大返工后，项目办公室只判断是否产生可复用经验，不做机械每日总结。
- 更新本文件时必须重写、合并、删除和压缩，不允许无限追加流水账。
