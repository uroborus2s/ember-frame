# 第十八章 白册外署

清明院外署比沈维桑想象得干净。

墙白，阶白，门上的铜环也擦得发亮。排水渠出口在外署后墙下，臭水从墙外流过，墙内却闻不到一点臭味，只有皂角和冷香。孟归藏从泥里爬出来，抹了把脸。

“做脏事的地方越干净，越说明它怕人闻见。”

外署辰时开白册廊。各地转来的档会在廊下分类：旧名、旧歌、旧血、旧路、旧械。沈维桑要找童声档，孟归藏要找署印，晏南枝要找能连向月下的外署路标。

他们混入送炭人群。沈维桑脸上抹煤灰，晏南枝换了灰衣。她仍站得太直，孟归藏看不下去，伸手把她肩往下一按。

晏南枝皱眉。

“别皱，”孟归藏说，“苦役皱不起这么好看的眉。”

她吸了口气，硬把肩沉下去。

白册廊里有很多孩子。

这比沈维桑想象的更可怕。他以为识别者会被关在密室，像刑具一样藏起来。可他们就站在廊中，被女吏牵着，看草绳、铜钱、碎石、旧布。孩子们穿得干净，脸也洗得干净，干净到不像从人家屋里抱出来的孩子。

一个小女孩看见日月碎石，唱了半句歌。女吏记下：可识旧纹。

另一个男孩看见红线，哭着喊娘。女吏记下：家牵未净，需再洗。

沈维桑的牙关慢慢咬紧。

晏南枝脸色难看。她没有说“残忍”这种大词，只低声问：“他们午饭吃什么？”

沈维桑看她。

她说：“我想知道他们是不是连饭也被编号。”

很快她就知道了。廊尾有白瓷碗，每碗稀粥上放一枚小木签。孩子按签取粥，不能换，不能多拿。一个年纪小的孩子把粥洒了半碗，女吏没有打他，只让他把洒在桌上的粥用指头刮回碗里。

沈维桑转开眼，怕自己忍不住。

童声档架在北廊。残阳坳的位置仍空着，旁边放着一只白蜡匣。匣中是沈照眠的腕血拓印，旁边写着：童谣残响稳定，家人牵绊强，可用于诱旧驿血脉。暂不洗尽，候监察官白翳复核。

沈维桑把副本拓下。原件不能动，他记得孟归藏的话。可记得不代表不疼。

廊外忽然有脚步。

女吏牵着那个唱过旧纹的小女孩走来。小女孩经过沈维桑身边时，停住，看着他腕上露出的红线。

她轻轻唱了一句：“旧马识途不识碑。”

沈维桑整个人僵住。

那声音不属于她。那是沈照眠的尾音借她嘴里过了一下，像远处有人隔着白墙敲门。

女吏抬头：“谁在那里？”

晏南枝抓起一排白牌，直接推倒。白牌哗啦落地，虫蜡针乱转。沈维桑拉住她冲向后廊。孟归藏从另一头跑来，怀里抱着署印盒，气喘得像快死。

“拿到了？”

“拿到一半。”

“印还能一半？”

“印泥和印章分开放，我只偷到印章！”

外署钟声大作。

白门一扇扇落下。沈维桑冲过第一道门时，回头看见那个小女孩站在满地白牌中。她的嘴唇动了动，没有声音。

哥哥。

沈维桑几乎回头。

晏南枝死死抓住他：“她不是照眠！”

“她在替照眠说话！”

“所以你更要出去。出去才能追真的。”

白门在他们身后合上。门缝里，小女孩的眼睛空而湿，像一只被洗得太干净的碗终于盛回了一滴水。

沈维桑把童声档副本按进怀里。

他欠她们每一个人一条出路。
