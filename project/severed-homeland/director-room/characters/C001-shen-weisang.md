## 1. 源头 Canon
owner: story-original
status: locked

- 身份：残阳坳猎户兼引路人，旧帝国驿道测绘官后代，第一季护送线主角。
- 年龄 / 时代位置：17 岁；肃明历 1226 年，从残阳坳屠村起点被推入旧驿与月下盟书线。
- 出身：金河南岸残阳坳人族山村，沈家承接旧驿测绘官残线，家中以草药、猎路、旧驿暗语保存记忆。
- 关键过往：父亲沈季衡表面死于山洪，实因藏匿月下地图被肃明处死；母亲罗青禾临终交付半枚日月驿令；妹妹沈照眠被清明院带走成为识别者。
- 核心伤口：小家被清明籍和清明香摧毁，妹妹被制度改造成追捕工具；他越想只救眼前人，越被迫看见陌生人的债也会落到自己手上。
- 性格底色：克制、实用、护短，天然不信“血脉”“正统”“复国”这类大词。他的善良不是柔软外露，而是先把代价算清，再冷着脸把人往身后拉；弱点是过早判断谁该被救、谁必须被放弃，尤其一碰到沈照眠就会失衡。
- 压力反应 / 说话质地：先看风向、水迹、脚印、出口和对方的手；话短、冷、带山路人的实用判断，情绪越重越少说。许诺后会把自己逼进死路；左肩旧伤、明劲反噬和灵翼残纹暴露必须让每次逞强都有身体代价。
- 关系变化：罗青禾的遗言把他从小家推上旧路；晏南枝从负担变成价值辩论的同路人；陆青砾、薛临墙、鹿弥让他承认陌生人也会落进自己的故土；白翳把他逼成两种秩序观的对手；沈照眠始终是未团圆的亲情伤口。
- 欲望：完成罗青禾遗言，把晏南枝送到月下盟书旧驿；找回沈照眠；查清沈季衡死因。
- 恐惧：宏大旗帜吞掉具体的人；自己为了护送不得不放弃某些人；妹妹认得出旧暗语却认不回哥哥。
- 行为底线：答应的事不改口；优先救眼前可救的人命，不让血牒、皇旗、旧物高过人命；不用灵翼残纹或明劲逃避代价。
- 人物弧光 / 完整成长轨迹：第一阶段只想守住母亲、妹妹和残阳坳，却被白册清查、罗青禾遗言和旧驿暗道推上护送路；第二阶段在金河与外署看见制度如何把孩子、粮牌和名字拆碎，并因沈照眠声音在东廊欠下不可抹平的债；第三阶段经墙下集市、灰墙军和北境雪线，学会把无姓者、守墙人和北境灾民纳入“该救的人”；第四阶段从沈季衡真相里明白月下路不能交给任何单一皇旗；季终在坍塌烽燧选择先救桥下的人，接受血牒残缺、盟书半页和不签册带来的裂缝。
- 不可改动事实：筑架已成、明劲残缺，第一季不得进入暗劲或内家；不得成为天选王者、少年战神、高阶法师或复国君主；灵翼残纹只能提供短促共鸣、路线感和旧驿反应。
- 原著关键段落来源：`chapter-001` 白册清查点到沈照眠；`chapter-003` 沈照眠被带走、罗青禾定下“送她去月下”；`chapter-035` 旧阵中读出父亲案；`chapter-045` 桥下救孩子与晏南枝毁血牒；`chapter-046` 接受新日月裂缝与下一条旧驿暗语。

## 2. 编剧影视化角色卡
owner: screenwriting

- 影视视觉要素：身高约 175 厘米，体重约 64 公斤，少年后期精瘦长骨架，肩背因常年背弓和走山路而紧实，腰腹薄但耐力强；左肩旧伤使静止时略压低左肩，拉弓或爆发明劲后左肩短暂僵硬；脸型偏窄，肤色有山风和烟火晒暗，手掌有弓弦茧、刀茧和草药细划痕。
- 服装与道具首读：灰褐猎衣、草药青内层、旧皮护腕、猎弓、短刀、路线包、半枚日月驿令、火后焦黑衣角；边墙段可加灰麻披风、旧皮肩护和雪线绑腿，但不能变成军官甲。
- 编剧定位：第一季行动主轴，不是天选救世主，而是被迫把“小家之痛”一路扩展成“救人之路”的猎户少年。
- 表演核心：话少、眼快、手先动；进场先看退路、水声、脚印、对方手腕和可用道具。情绪越重越短句，最痛时不解释。
- 对白质地：山路人的实用话，不说漂亮誓言。常用句式是判断、否定、反问和低声承诺，如“先活着”“路不问你认不认”。
- 可见行为锚点：藏兔、挡妹妹、按木纹、咬舌破清明香、收空白牌、割水绳、护档纸。每次救人都要付出身体代价。
- 禁止误读：不得写成复国少主、热血少年战神或万能破局者；他的价值在于选择眼前人命，不在于拥有血脉神迹。

## 4. 配音声音角色卡
owner: voice-room
source: Section 1 源头 Canon + Section 2 编剧影视化角色卡 + `screenwriting/season-screenwriting-main.md` + `screenwriting/02/screenwriting-main.md` + `screenwriting/03/screenwriting-main.md`
status: draft_voice_master_card_v001

- voice_id: C001-VOICELOCK-V001
- 声音母卡用途：沈维桑全季配音母音色与常用试声母句；用于后续 TTS / 人工录制 / 口型对齐前的声音锁，不替代分镜台词 cue。
- 声线：17 岁山路少年男声，低中声区，喉位略低但不能成熟军官化；声底干、短、带山风烟火和清明香后留下的轻微涩感。不是热血少年高喊嗓，也不是冷酷英雄低音炮。
- 语速：常态中速偏短句；判断路线、危险和代价时先停半拍再给结论；越急越低、越短，不加快到含糊。读母亲信和妹妹线时显著放慢，但不拖成哭诉。
- 呼吸：低位短气，常把气压在胸口；受伤、冰水、残纹反噬时出现断续吸气和尾句压断。行动前常有极短吸气，像先把痛吞下去再说话。
- 情绪层级：L0 冷静警觉；L1 实用否定 / 反问；L2 护短低声命令；L3 疼痛压住、字尾收紧；L4 妹妹 / 母亲伤口，声音更轻更慢但不放声哭；L5 罕见松动，只给很短的少年感喘息。
- 爆发方式：愤怒时不吼，改为句长变短、咬字变硬、尾音截断；真正失控前先出现沉默和呼吸空拍。若必须喊，喊声只能是身体被逼出的短促破口，不能变成战神宣言。
- 低声 / 沉默 / 哭腔 / 怒声规则：低声必须仍清楚；沉默要有呼吸和吞咽证据；哭腔只允许在读罗青禾信、沈照眠线索、残阳坳被清村等少数场景露出一瞬，不能拖尾；怒声压低而非抬高。
- 口音 / 咬字：普通话为主，可有轻微山路人口语硬度，句式像判断路、价钱和活命，不做文雅书卷腔；不得加入现代口头禅。
- 距离感：常态与人保持半步距离，声音不主动贴近；护人时距离变近但音量仍低；对晏南枝早期有刺但不是刻薄，是拒绝被旧旗叙事绑架。

### 母音色锚点

- 核心听感：少话、眼快、手先动；声音像一个先看退路、脚印、水声和对方手腕的人。
- 身体代价：左肩旧伤、残纹反噬、冰水和饥饿会让气口变短；每次强撑后必须听见轻微呼吸代价。
- 价值底线：不把血牒、皇旗、旧物放在人命前；因此重音多落在“活着”“人”“路”“账”“疼”“带走”等眼前词。
- 禁用方向：成熟将领嗓、少年燃喊、复国宣誓腔、冷酷反派腔、轻喜剧吐槽腔、万能男主自信腔。
