## 总导演裁决

反馈成立。`P-01-v0213-slow-action-preflight-review-20260622.mp4` 撤回，不得晋升 `P-01.mp4`，也不得继续作为 P-01 正式生产节奏模板。

失败性质不是“还差一点润色”，而是上游控制证据不足：

1. `自然速度` 被错误执行成了 `慢动作`。正确要求是 24fps 下 1x 真实动作速度，人物推搡、退步、撞门冲击都必须有正常起落，而不是延长成缓慢漂移。
2. `人物清晰` 不达标。低清 / 糊脸 / 糊人只能作为内部失败样片，不得交给用户当成可审看成片。
3. `C021 巨兽身份锁` 不达标。项目已有 `director-room/characters/C021-northern-symbiotic-beasts-template.md` 和 `director-room/characters/c021m.png`。P-01 的门外巨兽只能是 C021 破门猛犸 / 共生兽关系模板的镜头状态，不允许模型凭空长出新怪物。
4. `同一堵墙空间证据` 不达标。F1 必须同时看见关闭主门、连续黑石墙面、上方城头 / 门楼垛口和床弩 / 守兵轮廓；否则观众会以为撞门墙和城头墙是两个不相干空间。

## 给视频生成部的返工命令

视频部在美术部上述四项未通过前，不得重跑完整 P-01。

允许的下一步只有两个短测试：

1. `P01-F1E-NATURAL-IMPACT-TEST`
   - 时长：1.2 到 1.6 秒。
   - 速度：1x 自然速度，不得慢动作，不得 speed ramp，不得用尾帧停顿冒充动作。

2. `P01-F2D-SHARP-PUSHBACK-TEST`
   - 时长：1.4 到 2.0 秒。
   - 速度：1x 自然速度，C024 推人必须有起点、受力、反应、终点。
   - 必须看见：人物清晰，手接触清晰，脚步不是滑动，锁栅 / 粮仓方向仍可读。
