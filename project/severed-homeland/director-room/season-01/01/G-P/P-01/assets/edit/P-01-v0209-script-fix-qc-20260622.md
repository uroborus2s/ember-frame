# P-01 v0209 台词因果 / C024 声音清晰度 QC

## 用户问题

用户指出：`粮仓锁死，拉弩，退下去也是死` 听起来别扭，并且听感上像没有声音；更关键的是，观众不明白 `粮仓锁死`、`拉弩` 和 `退下去死` 之间有什么必然关系。

## 编剧 / 导演裁决

反馈成立。旧句 `粮仓锁死！拉弩！退下去也是饿死！` 撤回。

失败原因：

- 台词把地点状态、动作命令和生死后果硬并列，缺少“因为”。
- `拉弩` 是动作口令，但没有说明为什么此刻非回到床弩不可。
- `退下去也是饿死` 把威胁落在“饿死”上，和当前巨兽撞门 / 城门将破的即时危机不统一。

新版采用：

```text
粮仓封了！回弩位！门破了，都得死！
```

新版逻辑：

```text
粮仓 / 退路封死
  -> 军户退下去取不到粮，也逃不开
  -> 只能回到床弩位继续防门
  -> 城门一破，全墙人都死
```
