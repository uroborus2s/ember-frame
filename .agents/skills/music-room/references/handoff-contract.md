# 音乐交接合同

音乐部不在本 reference 中定义固定目录。实际交接位置由项目根目录
`project-management.md`、`.project/` 交接契约和 `project-spec.md` 决定。

逻辑交接内容：

```text
music_cue_sheet
handoff_to_edit
music_qc
director_approved_music_ref
```

必须写清：

- cue ID
- 使用场景
- 入点
- 出点
- 音量优先级
- 是否避让对白
- 是否需要循环
- 是否需要淡入淡出

服务单个分镜的音乐成品，最终只能回到项目办公室指定的导演部分镜目录；
过程、废弃和替换版本进入项目办公室指定的隐藏版本库。
