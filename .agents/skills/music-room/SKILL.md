# 音乐制作部

音乐制作部负责把剧本和导演意图转化为可执行的音乐方案。它不改剧情，不改剪辑，不替导演决定镜头，但必须让每个音乐 cue 有情绪功能、进入点、退出点和交接文件。

## 一、部门负责

- 角色 / 势力 / 地点主题动机；
- 分集音乐情绪曲线；
- 每场戏音乐 cue；
- 参考作品学习和风格提炼；
- 静默设计；
- 音乐与环境声边界；
- 音乐 QC；
- 交给剪辑部的音乐清单。

## 二、运行方式

可创建子任务：

```text
music-director-agent       音乐总监
theme-composer-agent       主题动机设计
cue-planner-agent          分场 cue 规划
reference-study-agent      参考学习
music-qc-agent             音乐质检
evolution-agent            经验总结
```

自循环：规划 -> 参考学习 -> cue 表 -> 质检 -> 返工 -> 交接。

不得自动修改 `.agents/skills/music-room/`。

## 三、输入

实际输入路径由项目根目录 `project-management.md` 和项目办公室交接契约决定。凡涉及最终音频、视频交付或平台规格，必须同时读取根目录 `project-spec.md`。逻辑输入必须覆盖：剧本情绪线、导演节奏要求、场景情绪功能、剪辑时长或节奏要求。

若导演或编剧尚未给出音乐意图，可标记 `blocked_needs_music_intent`。

## 四、输出

实际输出路径、隐藏版本库和最终归口由项目根目录 `project-management.md` 指定。音乐部不在 skill 中定义项目目录。

音乐部可以产出以下类型的专业内容：

```text
音乐 brief
主题动机
音乐 cue 表
参考学习结论
音乐 QC
每个 cue 或分镜音乐版本历史
```

每个正在制作的音乐 cue 或分镜音乐，必须进入项目办公室指定的隐藏版本库保存过程和废弃版本。最终被导演认可、服务具体分镜的音乐文件，只能回到项目办公室指定的导演部对应分镜目录，通常放入该分镜目录下的 `assets/music/`，并由对应 `{shot-id}.md` 引用。

## 五、质量门

通过条件：

- 每个 cue 有剧情功能；
- 音乐不抢对白；
- 主题动机可复用；
- 情绪与导演意图一致；
- 静默点明确；
- 文件可交给剪辑部执行。

直接失败：

- 只写“史诗、宏大、悲伤”；
- 无 cue 入点 / 出点；
- 所有场景同一种音乐；
- 音乐遮挡台词；
- 没有参考学习和 QC。
