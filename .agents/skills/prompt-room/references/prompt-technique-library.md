# 提示词技巧库

本库用于沉淀经过观察、复盘或项目验证后有稳定效果的提示词结构。它不是成品提示词仓库，而是提示词部把导演、美术和视频生成要求转成可执行提示词时的结构经验库。

使用本库时必须区分：

- `production_metadata`：给部门和 QC 看的任务、布局、编号、镜头说明、声音说明、箭头标注规则；
- `model_visible_prompt`：真正交给图片或视频模型看的内容；
- `control_ref_prompt`：用于生成角色卡、俯视图、九宫格、故事板等控制资产的提示词；
- `negative_prompt`：禁止出现的内容；
- `copy_ready`：可直接复制到工具中的最终版本。

禁止把内部标注、字幕、任务编号、UI 文字、红线箭头、地图路径、平台水印等误放进最终视频模型提示词，除非目标本身就是生成内部控制图或故事板。

## 经验总则

优秀提示词通常不是堆形容词，而是按生产目的组织信息：

```text
输出目标 -> 画幅/布局 -> 主体身份 -> 场景空间 -> 镜头语言 -> 动作/情绪 -> 风格/光影 -> 约束/QC
```

视频提示词比图片提示词更需要时间和运动：

```text
镜头基础信息 -> 场景信息 -> 运动信息 -> 主体与环境互动 -> 细节变化 -> 收尾画面处理
```

对 AIGC 视频最有价值的提示词不是“震撼、电影感、8K”，而是：

- 谁在画面里；
- 他/她在什么位置；
- 摄像机从哪里到哪里；
- 主体动作从什么状态变化到什么状态；
- 环境因动作发生什么变化；
- 镜头最后停在哪里；
- 哪些东西绝对不能变。

## PT-STRUCT-01 六段式视频提示词

适用：FPV、宏大运镜、角色运动镜头、微距镜头、长镜头、需要 5-15 秒连续变化的视频。

结构：

```text
1. 镜头基础信息
   景别、视角、镜头类型、镜头时长、画幅、镜头风格。

2. 场景信息
   地点、空间层次、前中后景、光源、天气、时代/材质、关键锚点。

3. 运动信息
   摄像机运动、主体运动、运动方向、速度变化、是否穿越/绕行/推拉/升降。

4. 主体物理时间互动效果
   人物、服装、头发、道具、地面、水、雾、尘、光影等随时间变化的互动。

5. 细节
   表情、手势、服装褶皱、粒子、反光、景深、局部材质、微小环境反馈。

6. 收尾画面处理
   镜头最终落点、构图稳定状态、角色最终姿态、情绪余韵、剪辑可接点。
```

经验：

- 每段只写可见内容，避免把抽象主题当成画面指令。
- 运动方向要同时写主体和镜头，不要只写“镜头很震撼”。
- 长镜头要写起点、中段、终点；超过 5 秒建议拆成分秒提示词。
- 微表情提示词要写肌肉和眼神变化，如“眼睑轻抬、嘴角压住、呼吸变浅”，不要只写“复杂情绪”。

## PT-BOARD-01 草图故事版提示词

适用：打斗、追逐、动作桥段、镜头节奏不清、转场不顺、先验证镜头是否看得懂。

结构：

```text
任务：生成一张手绘风格分镜草图。
故事/动作：{桥段内容}
布局：4x3，共 12 个镜头，每行 4 格，共 3 行。
线条：快速、有力的铅笔线，重点突出动作张力和镜头节奏。
每格必须包含：镜头类型、角色动作、运动方向、表演提示、音效/声音提示。
标注：用不同颜色箭头区分角色运动、镜头运动、视线方向和冲击方向。
串联要求：12 个镜头必须构成完整动作逻辑，镜头切换和动作衔接清楚。
```

为什么有效：

- 先用低成本草图检查“观众是否看得懂”；
- 用箭头把运动逻辑外显，避免视频生成时动作乱跳；
- 强制每格有镜头类型，避免分镜全是相似构图；
- 给剪辑和视频生成部提供动作接点。

QC：

- 失败：12 格只是漂亮姿势，没有起承转合；
- 失败：每格都是同一景别；
- 失败：箭头没有区分主体、镜头、视线；
- 失败：动作无法从上一格顺到下一格。

## PT-BOARD-02 导演故事版提示词

适用：短片、PV、概念片、剧集关键段落、需要统一视觉和导演意图的镜头组。

结构：

```text
任务：生成一张电影制作板，用于展示短片/镜头组的完整概念。
故事：{具体故事内容}
比例：16:9。
布局：简洁网格，镜头编号清晰，避免镜头场景过于相似。
顶部栏：整体创意约束，包括镜头数量、统一调色、通用环境、主要角色、风格关键词。
角色与风格参考：正面、背面、侧面、特写、服装和配饰参考。
具体故事板：每个画面标注摄影机类型/镜头感、景别、运动方式、动作与情绪发展。
整体要求：连贯、电影化、专业，能作为导演前期拍摄指导。
```

为什么有效：

- 把“好看”改成“这组镜头要讲什么”；
- 让角色、色彩、场景和镜头数量在同一张板上被统一约束；
- 可以作为导演部、美术部、提示词部、视频部、剪辑部共同对照的中间件。

QC：

- 失败：只有氛围图，没有镜头编号和镜头职责；
- 失败：每格都像海报，没有可拍摄的动作；
- 失败：角色参考和故事镜头不一致；
- 失败：色彩和场景在不同格之间漂移。

## PT-CHAR-01 影视角色人物版提示词

适用：主角、重要配角、反复出现人物、角色漂移严重、需要同一身份贯穿多镜头。

结构：

```text
任务：生成一张影视角色人物版，用于锁定人物一致性。
人物描述：{年龄、身份、体态、脸型、发型、服装、气质、可见特征}
画面风格：电影级光影、真实材质、统一色彩系统、白色无干扰背景、高信息密度排版。
画面布局：
左侧：高质量角色半身或全身主视觉。
右侧：模块化角色信息系统。
模块包含：正面/侧面/背面三视图、面部细节、眼睛/鼻子/嘴唇/耳饰裁切、发型、服装材质、配饰、表情、动作姿态。
整体要求：UI 风格统一，文字区规整，所有模块视觉统一。
```

经验：

- 角色图要锁定“可重复识别特征”，不要只写美貌、气质、氛围。
- 角色特征按优先级写：脸型/五官 -> 发型 -> 服装轮廓 -> 材质 -> 配饰 -> 姿态。
- 生成视频时优先引用角色主视觉、三视图、面部裁切、当前集状态卡，而不是只引用文字。

QC：

- 失败：没有三视图或细节裁切；
- 失败：主视觉和模块里的角色不像同一个人；
- 失败：服装材质没有明确纹理和轮廓；
- 失败：只产出美图，没有可供视频复用的身份锚点。

## PT-SCENE-01 场景俯视图提示词

适用：室内空间、迷宫、墓室、城门、战场、院落、同一地点多镜头、角色调度复杂。

结构：

```text
任务：绘制一份场景俯视平面图。
场景：{地点和类型}
视角：俯视。
风格：黑白线条工程图，纯白背景，仅用黑线。
禁止：色彩、阴影、渲染、透视装饰、网格背景。
内容：清楚划分主要区域、入口、出口、通道、房间、核心道具、障碍物、角色/机位可移动区域。
标注：用简洁线条和编号标注陈设，不制造复杂文字。
质量：分区明确、比例清楚、线条疏密有致、可作为 camera map 和 blocking map。
```

经验：

- 俯视图的目标不是好看，而是锁定空间拓扑。
- 对视频生成来说，入口、出口、中心锚点、前中后景、遮挡物比装饰更重要。
- 俯视图进入视频提示词时要转成“空间关系语言”，不要把图纸文字直接塞给模型。

QC：

- 失败：像插画而不是平面图；
- 失败：空间没有入口/出口/中心锚点；
- 失败：道具很多但无法判断位置关系；
- 失败：后续分镜无法从图中找到机位和运动路线。

## PT-SCENE-02 场景九宫格提示词

适用：同一场景多角度镜头、正反打、绕场运动、场景身份容易漂移。

结构：

```text
任务：基于同一场景生成 3x3 九宫格方向参考。
场景：{场景名称和核心锚点}
布局：3x3，每格展示同一空间的不同角度。
角度：正面、背面、左侧、右侧、入口方向、出口方向、俯视/高位、低角度、关键道具特写。
风格：统一材质、统一光源、统一色彩、统一时代/空间设定。
要求：每格必须保留相同核心锚点，使观众能判断这是同一地点。
```

经验：

- 九宫格必须“同一空间不同角度”，不是九张相似氛围图。
- 每格都要保留 1-3 个共同锚点，如门、柱、祭台、窗、霓虹牌、雕像、中心道具。
- 给视频模型使用时，按镜头方向只引用对应角度，不要把整张九宫格当成万能图。

QC：

- 失败：九格像九个不同地点；
- 失败：锚点缺失，无法确认空间连续性；
- 失败：光源方向每格都不同；
- 失败：关键道具的位置不稳定。

## PT-NEG-01 控制图与成片提示词分离

适用：所有从故事板、角色卡、俯视图、九宫格进入视频生成的流程。

规则：

- 生成控制图时，可以要求编号、箭头、标签、模块、白底、网格、排版。
- 生成成片画面时，必须移除编号、箭头、标签、UI、字幕、教程风文字、手机界面、平台水印。
- 成片视频提示词只保留画面内真实存在的摄影、美术、动作、情绪、光影和物理互动。
- 内部 QC 项写在 `production_metadata`，不要混入 `model_visible_prompt`。

成片负面词模板：

```text
no text, no subtitles, no labels, no arrows, no diagrams, no UI, no phone screen, no social media overlay, no watermark, no storyboard panels, no split-screen layout, no tutorial card
```

## PT-QC-01 优秀提示词入库标准

一个提示词只有满足以下条件，才可以加入技巧库：

- 有明确用途：角色锁定、空间锁定、故事板、视频运镜、微表情、转场、声音提示等；
- 结构可复用，而不是只适用于单张图；
- 能解释它解决了什么生产问题；
- 能拆成 `metadata / model_visible / negative / copy_ready`；
- 有失败边界，知道什么情况下不能直接使用；
- 后续项目能按同一结构替换变量继续使用。

入库记录格式：

```text
编号：
名称：
来源：
适用场景：
结构模板：
关键经验：
常见失败：
可转交部门：
更新日期：
```
