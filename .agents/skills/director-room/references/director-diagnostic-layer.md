# 导演诊断层

本文件定义导演学院、分镜医生、转场医生和观众盲测 QC 的强制流程。它不是新的创作部门，而是总导演审判镜头时必须使用的专业诊断层。

## 触发场景

出现以下任一问题时必须启用：

- 分镜看完不知道在讲什么；
- 镜头只是漂亮，没有故事功能；
- 转场像素材拼接，没有因果和切点；
- 角色、场景、声音、动作或情绪在相邻镜头中漂移；
- AIGC 视频宏大但不表演、不叙事、不像专业导演拍摄；
- 用户要求学习导演、分镜、编剧或 AIGC 制作方法并落到 skill。

## 总原则

任何镜头都必须先成立为叙事，再成立为画面，再成立为 AIGC 生产任务。顺序不可反。

```text
剧本真相
  -> 人物目标和阻力
  -> 观众此刻必须知道/误会/感受什么
  -> 可见行动和状态变化
  -> 镜头目的与画面读法
  -> 相邻镜头衔接合同
  -> AIGC 生产证据需求
  -> 导演签署或返工
```

## 导演学院

导演学院负责把学习源转成当前项目的判断题。

每集必须生成：

- 本集导演命题；
- 本集观众观看秩序；
- 本集高风险场景清单；
- 本集非任意镜头规则；
- 每类场景的训练题和拒绝项。

非任意镜头规则：

```text
如果一个景别、机位、运动、光线、声音或转场不能说明戏剧目的，就不得使用。
```

每个镜头必须回答：

- 这一镜为什么存在；
- 观众第一眼被要求看哪里；
- 观众第二眼才应该发现什么；
- 人物状态从什么变成什么；
- 哪个动作、表情、声音或空间证据让这个变化可见；
- 删除这一镜会损失什么；
- 为什么必须用这个景别、机位、运动和光线；
- 这一镜如何进入下一镜。

## 分镜医生

分镜医生负责判断分镜是否可读。它不重写分镜，只写诊断和返工要求。

### 八问门槛

每个分镜必须通过：

```text
1. 为什么存在？
2. 观众第一眼看哪里？
3. 观众第二眼发现什么？
4. 角色正在做什么可见行动？
5. 入镜状态是什么？
6. 出镜状态是什么？
7. 删除会损失什么？
8. 如何接上一镜并推向下一镜？
```

### 直接失败

- 只有气氛，没有可见行动；
- 只有画面设定，没有人物目标或状态变化；
- 只有心理说明，画面无法看见；
- 分镜删掉后不影响信息、情绪、关系、空间或节奏；
- 镜头目的、主体焦点、动作和转场互相不支持；
- 观众必须读导演解释才能理解镜头。

### 返工写法

```text
failure:
  shot_id: <分镜 ID>
  symptom: <观众看不懂/角色动作不清/镜头目的空/删镜无损失>
  evidence: <来自分镜文件的具体句子或缺失字段>
  return_to: <storyboard-agent/shot-planner-agent/cinematographer-agent/...>
  revision_order: <必须改什么>
  acceptance: <怎么判断修好>
```

## 转场医生

转场医生负责把“下一镜”变成“为什么必须切到下一镜”。

### 转场合同

每组相邻分镜必须写：

```text
previous_exit_state:
next_entry_state:
cut_point:
transition_type:
transition_motivation:
continuity_locks:
audience_effect:
edit_risk:
```

`transition_motivation` 必须至少命中一种：

- `action`：动作切，身体动作或物体运动自然接续；
- `eyeline`：视线切，上一镜看向某物，下一镜揭示所看；
- `sound`：声音桥，声音先行或延续；
- `emotion`：情绪桥，情绪在下一镜延续、释放或反转；
- `information`：信息推进，下一镜回答上一镜留下的问题；
- `space`：空间推进，下一镜重建或推进空间关系；
- `match`：形状、运动、颜色、构图或动作匹配；
- `contrast`：有意反差，制造讽刺、冲击或主题对照。

### 直接失败

- 只写“切到下一镜”；
- 上一镜没有出点，下一镜没有入点；
- 动作方向、视线方向、道具状态或光线无故改变；
- 破轴没有过桥镜头或空间动机；
- 观众不知道为什么进入下一镜；
- 声音、音乐或静默没有进入点和退出点。

## 观众盲测 QC

观众盲测必须假装没有读过剧本解释，只根据分镜能看见和听见的证据理解故事。

### 五问盲测

每个分镜组必须回答：

```text
1. 谁在场？
2. 在哪里？
3. 谁想做什么？
4. 本镜头或本组发生了什么状态变化？
5. 为什么自然进入下一镜或下一组？
```

### 通过标准

- 普通分镜组：五问至少四项清楚，且不能错过核心剧情变化；
- 关键分镜组：五问必须全部清楚；
- 情绪型分镜组：剧情可留白，但人物状态变化和情绪流向必须清楚；
- 悬疑型分镜组：可以让观众不知道真相，但必须知道自己正在被引导产生什么疑问。

### 直接失败

- 看不出主角是谁；
- 看不出场景关系；
- 看不出动作目的；
- 看不出前后镜头关系；
- 情绪突然跳变但没有动作、声音或信息依据；
- 为了炫技牺牲观众理解。

## AIGC 生产适配

导演诊断层不写最终模型参数，但必须把通过的导演判断转化为后续生产约束。

每个分镜至少说明：

- 需要哪些角色身份参考、场景参考、首帧、尾帧或控制图；
- 哪些运动只能通过短镜头、分段、FLF2V、多关键帧或后期剪辑实现；
- 哪些表情、动作或空间关系不能只靠文生视频；
- 哪些镜头需要先做分镜图、参考帧或低模验证；
- 哪些镜头必须回传给导演复审。

若 AIGC 能力不足以完成导演目的，不得降低导演标准；应标记为 `blocked_needs_asset_or_control_evidence`、拆分镜头、改用可控生产方式，或退回总导演重设镜头方案。

## 总导演签署门槛

总导演签署前必须看到：

- 导演学院规则已写入本集或分镜；
- 分镜医生通过或明确返工；
- 转场医生通过或明确返工；
- 观众盲测 QC 通过或明确返工；
- 所有返工都映射到具体员工、字段、分镜和验收标准。

任一关键门槛失败，不得进入后续图片、视频、声音或剪辑生产。
