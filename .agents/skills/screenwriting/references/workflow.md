# 编剧部工作流

## 零、编剧部创作信条

编剧是文学创作者，是作家，不是剧情搬运工，也不是填表员。

每一集都决定这部剧的生死，决定观众的喜怒哀乐。编剧必须带着神圣感、敬畏感和责任感创作：剧本要有戏剧性，要让人沉沦；也要有美、有善、有勇气、有悲悯，让观众从故事里带走更明亮的东西。

结构服务生产，文学赋予灵魂。可执行只是底线，真正的目标是写出有生命、有余味、有人的光的作品。

## 一、总流程

```text
story-original 质量门通过
  -> 读取 story-original 内的原著、故事圣经和 adaptation-handoff
  -> 分集改编结构
  -> 场次拆解
  -> 分镜剧本说明
  -> 对白和旁白
  -> 角色语气 / 音色 / 行为说明
  -> 音乐和声音意图
  -> 整合结构化文学剧本主稿
  -> 剧本 QC
  -> 导演部交接
```

编剧部唯一输入源是 `story-original/`。`bible`、人物设定、场景设定、连续性、视觉风格、分集大纲、故事梗概都必须收进 `story-original/` 后再交给编剧部。

每集唯一强制输出是项目办公室指定路径中的一份结构化文学剧本主稿：

```text
<project-office-designated screenwriting main script path>
```

项目启用角色总卡时，编剧部还要更新每个相关角色文件中的 `Section 2. 编剧影视化角色卡`。角色总卡目录由项目办公室指定；采用导演部全局入口的项目通常位于：

```text
director-room/characters/CHAR-*.md
```

编剧部只能修改 Section 2，不得修改 Section 1 源头 Canon、Section 3 美术视觉角色卡、Section 4 配音声音角色卡或 Section 5 视频执行角色卡。

## 二、改编戏剧性

原著改剧本不是搬运情节，而是把小说里的信息、心理、设定重新组织成有欲望、有阻力、有误会、有揭露、有代价、有反转、有不可逆变化的戏。

每集必须回答：

- 主角想要什么；
- 他为什么现在必须要；
- 谁或什么阻止他；
- 他付出什么代价；
- 哪个信息被隐藏、误读或迟到；
- 哪一刻发生揭露、反转或选择；
- 结尾留下什么新悬念或新危机。

每场必须回答：

- 入场状态是什么；
- 场内冲突是什么；
- 谁占上风；
- 情绪如何转向；
- 结尾发生什么不可逆变化；
- 为什么必须进入下一场。

每个分镜必须回答：

- 观众这一镜必须看见什么；
- 人物正在掩饰什么、压住什么、爆发什么；
- 动作如何暴露内心；
- 声音、环境、道具如何帮戏；
- 这一镜如果删掉，会不会损失剧情或情绪。

## 四、角色总卡中的编剧影视化角色卡

项目启用跨部门角色总卡时，编剧部负责把原著部的源头 Canon 转成影视剧本可执行的人物表演和语言控制。

编剧部只写：

```text
## 2. 编剧影视化角色卡
owner: screenwriting
source: Section 1 源头 Canon
status: draft | locked | needs_fix

- 戏剧功能：
- 剧中人物目标：
- 台词风格：
- 口头禅 / 常用句式：
- 音色、气口、停顿：
- 情绪遮掩方式：
- 常见动作：
- 镜头里必须看见的状态：
- 每集状态变化：
- 禁止写偏：
```

写作要求：

- 不能改源头 Canon；
- 不能替美术部写视觉定稿；
- 不能替配音部写声音锁；
- 必须让美术部知道角色应该如何被看见；
- 必须让配音部知道角色应该如何被听见；
- 必须让导演部知道角色在镜头中如何行动和变化；
- 若源头 Canon 不足，退回 `needs_story_source_fix`。

## 五、分集剧本

每集必须写清：

- 本集一句话剧情；
- 开场 5 秒钩子；
- 主角目标；
- 外部阻力；
- 小高潮；
- 结尾钩子；
- 观众必须看懂的信息；
- 不允许提前解释的信息；
- 不可改动因果。

## 六、场次拆解

每场戏必须回答：

- 谁想要什么；
- 谁阻止谁；
- 这个场景为什么发生；
- 场景结束后发生了什么不可逆变化；
- 下一场为什么自然发生。

## 七、分镜剧本说明

每个镜头段写：

```text
镜头段 ID
剧情功能
观众必须看见什么
人物关系
可见行动
道具状态
情绪变化
声音或音乐意图
转场依据
禁止误读项
```

这不是最终导演机位，但必须让导演知道表达重点。

## 八、对白

关键台词必须检查：

- 是否这个角色会说；
- 是否一听懂；
- 是否有潜台词；
- 是否有气口、停顿、重音；
- 是否方便配音；
- 是否避免背设定。
