# 编剧部质量门

## 评分表

| 维度 | 分值 |
| --- | ---: |
| 原著改编忠实度 | 10 |
| 改编戏剧性 | 15 |
| 分集完整度 | 10 |
| 观众可理解度 | 10 |
| 人物行为一致性 | 12 |
| 台词文学性与可听性 | 12 |
| 画面可见性 | 8 |
| 转场自然度 | 8 |
| 声音和音乐意图 | 5 |
| 结构化主稿与下游交接 | 5 |
| 精神内核与人性之光 | 5 |

## 直接失败

- 台词晦涩到观众无法理解；
- 角色用对白讲设定；
- 转场没有视觉、声音、动作或情绪依据；
- 角色没有音色和行为提示；
- 镜头段没有可见行动；
- 下游无法判断该拍什么；
- 主稿把改编信息拆散到多个文件，导致下游需要拼信息；
- 项目启用角色总卡时，相关角色没有 `Section 2. 编剧影视化角色卡`；
- 编剧影视化角色卡背离 `Section 1. 源头 Canon`；
- 编剧部直接修改源头 Canon、美术视觉角色卡或配音声音角色卡；
- 只有结构，没有文学性、戏剧性和人的光；
- 没有体现编剧作为文学创作者的神圣感、敬畏感和责任感。

## 精神内核检查

每集必须回答：

- 本集要守护的人性价值是什么；
- 本集希望观众带走什么情感；
- 本集最有文学力量的一场戏是什么；
- 本集最能打动人的一句台词或一个动作是什么；
- 本集有哪些严肃情感不能被娱乐化消解。

## 角色总卡检查

项目启用角色总卡时，每个本集关键角色必须通过：

- 是否读取并尊重 `Section 1. 源头 Canon`；
- 是否只更新 `Section 2. 编剧影视化角色卡`；
- 戏剧功能是否清楚；
- 剧中目标是否清楚；
- 台词风格、口头禅、气口、停顿是否可配音；
- 情绪遮掩、常见动作和镜头可见状态是否可拍；
- 每集状态变化是否能接入 `screenwriting-main.md`；
- 禁止写偏项是否明确；
- 美术部和配音部是否能直接据此继续工作。
