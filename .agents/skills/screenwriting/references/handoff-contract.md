# 编剧到导演交接合同

编剧部交给导演部的是一份项目办公室指定路径中的结构化文学剧本主稿。
编剧部不在本 reference 中定义固定目录；实际正式剧本路径、历史归档和返工入口
由项目根目录 `project-management.md` 与 `.project/` 交接契约决定。

主稿不得把导演、配音、音乐、美术、提示词、视频和剪辑需要的信息拆散到多个强制
输出文件里。所有生产信息必须在同一份主稿内按“剧 -> 集 -> 分镜组 / 场景段落
-> 单分镜”的结构写清。

主稿交接必须写清：

- 剧情因果
- 人物目标
- 改编戏剧性
- 本集精神内核
- 角色总卡中的编剧影视化角色卡更新状态
- 关键台词含义
- 必须看见的动作
- 必须保留的道具
- 服装、表情、动作和环境细节
- 转场依据
- 配音语气
- 音乐和声音意图
- 导演可发挥空间
- 导演不可改变项
