# 最终交付合同

成片交付部不在本 reference 中定义固定目录。实际交付位置由项目根目录
`project-management.md`、`.project/` 最终批准门和 `project-spec.md` 决定。

最终交付必须包含：

```text
delivery_spec
final_qc
release_manifest
director_approved_final_video_ref
final_export_ref
```

其中清晰度、画幅、编码、音频、字幕、文件格式和平台要求以 `project-spec.md`
为准；目录归口、版本冻结和验收状态以项目办公室契约为准。
