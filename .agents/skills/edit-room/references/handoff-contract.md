# 剪辑到成片交接

剪辑部不在本 reference 中定义固定目录。实际交接位置由项目根目录
`project-management.md`、`.project/` 交接契约和 `project-spec.md` 决定。

逻辑交接内容：

```text
edit_decision_list
subtitle_script
preview_manifest
edit_qc
director_approved_preview_or_final_cut_ref
```

服务单个分镜的剪辑交接材料，最终只能回到项目办公室指定的导演部分镜目录；
整集或成片交付材料进入项目办公室指定的交付归口。
